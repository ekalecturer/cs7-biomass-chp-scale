Honest caveat: the paper publishes min/base/max ranges for its eight uncertain variables (Table 5) but not the exact distribution shape, correlation structure, or random seed used inside its Crystal Ball-style model. This reconstruction (both the notebook and this browser simulator) uses triangular distributions built from those ranges. It reproduces the paper's deterministic NPVs exactly by disclosed calibration, and reproduces the DIRECTION of the Monte Carlo bias at the two smaller sizes, but not at 1,940 kWe, where this reconstruction's simplified model produces an upward shift instead of the paper's reported downward one. This is stated directly, not hidden — see the notebook and README for the full explanation.

The lesson

This paper modeled one biomass gasification CHP technology at three capacities using one consistent methodology. At the two smaller sizes, the deterministic base case undersold the project relative to its own Monte Carlo mean, by 92% and 58%. At the largest size, the same modeling approach oversold the project, by 32%. Scale itself changed which way the single-point estimate erred. There is no universal rule for whether a deterministic feasibility number runs conservative or optimistic — only the specific model, at the specific scale, run through its own uncertainty.
